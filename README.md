# 配管切寸法計算

継手の組み合わせと実測値から、パイプの切寸法を自動計算する現場用アプリ（PWA）。

**▶ https://takanori0.github.io/pipe-cut-calc/**

## 特徴

- **完全オフライン動作** — 一度開けば圏外の現場でも全機能が使える（Service Worker）
- **ホーム画面に追加** — iPhone: Safariで開く→共有→「ホーム画面に追加」／Android: Chromeのメニュー→「アプリをインストール」
- TS継手（VP/HI）・DV継手（VU）・ねじ込み（JIS B2301）・突合せ溶接（JIS B2311）の4系統・34継手
- 切寸法＝測定値−Z左−Z右 を式付きで表示。測定基準は芯／端面／パイプ外側・内側から選択
- オフセット計算（4場面・角度不明の実測逆算）／勾配／BOP・COP・TOP高さ換算／逃げ・ヤリトリ判定
- 電卓配列テンキー・手袋対応56pxタップ・屋外/屋内表示切替・切断リスト・読み合わせモード
